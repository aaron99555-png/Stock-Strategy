資料庫權限不足

系統嘗試連線至雲端時遭到拒絕。因為我們目前使用無 API Key 的 REST 連線方式，您必須將資料庫設為公開。

  1. 前往 Firebase 控制台，開啟 Realtime Database 頁面。
  2. 點擊上方的「規則 (Rules)」標籤。
  3. 將規則修改為允許讀寫：
    {
      "rules": {
        ".read": true,
        ".write": true
      }
    }
  4. 點擊「發布」，重新整理網頁即可成功連線！
