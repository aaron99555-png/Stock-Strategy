缺少 Firebase 金鑰

系統偵測到您可能尚未填寫專屬的 API Key，或尚未在 Firebase 開啟「匿名登入」權限，導致無法成功連線至雲端。

  1. 請至 Firebase 控制台打開您的 stockstrategy-492a1 專案。
  2. 前往「專案設定 > 一般 > 網頁應用程式」。
  3. 將您的 apiKey 填入此 HTML 檔案第 470 行左右的 myFirebaseConfig 設定區塊中。
  4. 請確認在 Firebase 左側選單已啟用 Authentication (匿名登入) 與 Firestore Database。
